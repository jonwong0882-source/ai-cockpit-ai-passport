1. Download the GitHub source linked in the description. On an always-on Mac signed in to Codex, follow README to install the bridge and provide an HTTPS endpoint reachable from your phone hotspot.
2. Flash the community firmware, then connect to the Mac by USB. Follow README to write your endpoint and private key using the configuration tool. This resets saved Wi-Fi; configure the API before phone provisioning.
3. Tap OK to wake, hold OK for SETTINGS, select BLE / START with the arrows and press OK. In the EspBlufi phone app, scan BLUFI_CodexBoard, connect, select Station/STA, enter the 2.4GHz Wi-Fi or hotspot name/password and confirm. An iPhone hotspot may need Maximize Compatibility. Successful connection reboots the board; tap OK again.
4. Once SYNCED appears, arrows cycle nine pages. Short OK changes the map range or syncs other pages; hold OK opens settings or returns. The display blanks after 30 idle seconds.
5. Use WI-FI / RECONNECT if disconnected. To change networks, start BLE setup again. Check the network name/password and retry if connection fails.
