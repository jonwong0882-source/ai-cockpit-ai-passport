1. On an always-on Mac signed in to Codex, follow the GitHub README to install the bridge and provide an HTTPS endpoint reachable from your phone hotspot.
2. Flash the firmware, then connect the Mac by USB. Follow README to write your own endpoint and key with the configuration tool. This clears Wi-Fi settings: configure the API before provisioning Wi-Fi.
3. Tap OK to wake; hold OK for SETTINGS. Select BLE / START with the arrows and press OK. In the EspBlufi phone app scan BLUFI_CodexBoard, connect and select Station/STA. Enter the 2.4GHz Wi-Fi or hotspot name and password, then confirm. An iPhone hotspot may need Maximize Compatibility. Success reboots the board; tap OK to wake again.
4. Once SYNCED appears, arrows change pages. Short OK switches the map range or refreshes other pages; hold OK opens settings or returns. LIGHT changes brightness and SLEEP changes idle timeout; selections are saved. Background sync continues with the screen off.
5. If disconnected, select WI-FI / RECONNECT. Start BLE setup again to change networks. Check the network name and password, then retry if connection fails.
