1. 下载介绍中的 GitHub 源码，在已登录 Codex 的常驻 Mac 上按 README 安装后端，并准备手机热点也能访问的 HTTPS 接口。
2. 烧录社区固件后用 USB 接 Mac，按 README 运行配置工具，写入自己的接口地址及密钥。此步骤清除 Wi-Fi 设置，须先做再配网。
3. 短按确定唤醒，长按进入 SETTINGS；上下选 BLE / START，确定开启。手机 EspBlufi App 扫描 BLUFI_CodexBoard，连接后选 Station/STA，输入 2.4GHz Wi-Fi／热点名称和密码并确认。iPhone 热点必要时开“最大兼容性”。连接成功会重启，再按确定唤醒。
4. 显示 SYNCED 后，上下循环九页；概览短按确定切换范围，其他页短按刷新，长按进入设置／返回。30 秒无操作自动息屏。
5. 断网可在设置选 WI-FI / RECONNECT；换网重新开启 BLE 配网。未连上时核对名称、密码并重试。
